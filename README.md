# 가상거래소

캔들차트로 시세를 보여주고, 레버리지 롱/숏 포지션으로 거래하며, 직접 발행한 뉴스가 실제로 주가를 움직이는
가상 주식 거래 시뮬레이터입니다. 순수 HTML/CSS/JS로만 만들어져 있어 GitHub Pages에 올리면 바로 동작합니다.

## GitHub Pages에 올리는 방법

1. GitHub에 새 저장소를 만듭니다.
2. 이 폴더 안의 `index.html`, `style.css`, `script.js` 세 파일을 저장소 루트에 업로드(또는 push)합니다.
3. 저장소 **Settings → Pages**로 이동합니다.
4. **Source**를 `Deploy from a branch`로 설정하고, 브랜치는 `main`(또는 `master`), 폴더는 `/ (root)`를 선택 후 저장합니다.
5. 1~2분 후 `https://<사용자명>.github.io/<저장소이름>/` 주소에서 접속할 수 있습니다.

로컬에서 미리 보려면 이 폴더에서 `index.html`을 브라우저로 더블클릭해서 열어도 됩니다.

## 사용법

- **왼쪽 상장 기업 목록**: 클릭해서 종목을 선택합니다. `+ 신규` 버튼으로 원하는 이름·티커·분류·시작가의 기업을
  직접 만들 수 있습니다.
- **가운데 캔들차트**: 국내 관행대로 빨강=상승, 파랑=하락입니다. 상단 툴바에서 `추세선`(두 점 클릭), `수평선`(한 점 클릭)을
  그릴 수 있고 `전체 지우기`로 해당 종목의 그림만 지울 수 있습니다. `기업 수정`으로 이름/분류를 바꾸거나 기업을 삭제할 수 있습니다.
- **하단 거래 패널**: 수량과 레버리지(1~20배)를 정해 롱(상승 베팅) 또는 숏(하락 베팅) 포지션을 엽니다.
  진입가 대비 `1/레버리지`만큼 불리하게 움직이면 자동 강제청산됩니다.
- **오른쪽 소식통**: `+ 뉴스`로 종목·헤드라인·본문·성격(호재/악재/중립)·파급력(약/중/강)을 정해 속보를 발행하면
  즉시 피드에 뜨고, 이후 몇 틱에 걸쳐 그 종목 캔들에 반영됩니다.
- **내 포지션**: 실시간 평가손익과 수익률을 보여주며, `청산` 버튼으로 원할 때 정리할 수 있습니다.
- 상단 바의 NOSPI 지수는 모든 종목의 평균 등락률을 반영한 합성 지수이고, USD/KRW·투자자 수는 분위기를 위한
  장식용 수치입니다.
- 모든 데이터는 브라우저 localStorage에 저장되어 새로고침해도 유지되며, 하단 `전체 초기화`로 언제든 처음
  상태(현금 1천만원)로 되돌릴 수 있습니다.

## 커스터마이징

- `script.js` 상단 `DEFAULT_STOCKS` 배열로 처음 상장되는 기업 구성을 바꿀 수 있습니다.
- `STRENGTH_RANGE`, `IMPULSE_TICKS`로 뉴스가 주가에 미치는 영향의 크기·지속 시간을 조절할 수 있습니다.
- `CANDLE_SIZE`(캔들 하나당 틱 수), `TICK_MS`(틱 주기)로 차트 속도를 조절할 수 있습니다.
- `style.css`의 `:root` 변수에서 색상·폰트를 바꿀 수 있습니다.
